# 小众点评

个人美食记录工具。吃到好吃的拍一张，记上评分、标签和一句话评价，以后想找某道菜、某家店，搜一下就出来。

数据存在自己的数据库里，照片直接以压缩后的格式入库，不经过任何第三方服务。

## 功能

- **拍照记录**：拍照或从相册选图，自动裁剪压缩，一张图一条记录
- **评分 + 标签**：给菜打星、打标签（比如「川菜」「甜品」「回购」）
- **搜索**：按菜名、餐厅名、评价内容关键字搜索
- **筛选**：按标签、按日期过滤
- **统计**：总记录数、本月新增、平均消费
- **导入导出**：数据可以整体导出成 JSON 备份，也可以导入恢复
- **手机适配**：页面按手机设计，浏览器里可以「添加到主屏幕」当 App 用

## 运行

需要 Node.js 和 PostgreSQL，详细步骤见 [部署说明](部署说明.md)。

```bash
npm install
cp .env.example .env   # 填入数据库密码
npm start
```

然后浏览器打开 `http://localhost:3000/xiaozhong.html`。

## 技术构成

前端是单个 HTML 页面，没有构建步骤；后端是 Express + PostgreSQL；照片在前端压缩成 base64 后直接入库（单条记录一个字段），数据库备份即完整备份。
